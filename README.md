# DelOs

## El sistema operativo para empresas de servicios.

DelOs nace para resolver un problema real: las empresas de servicios pierden tiempo, oportunidades de negocio e información por trabajar entre WhatsApp, llamadas, agendas y planillas.

Nuestra misión es simple:

Priorizar al cliente y potenciar el tiempo del técnico.

## Objetivos

- Centralizar toda la información del negocio.
- Automatizar tareas repetitivas.
- Evitar que un cliente quede sin respuesta.
- Organizar visitas, presupuestos y seguimientos.
- Asistir al técnico sin reemplazar su criterio.

## Principios

- El cliente primero.
- La IA asiste, el técnico decide.
- Nunca prometer lo que no está confirmado.
- Ningún cliente queda sin seguimiento.
- La simplicidad es una ventaja competitiva.
